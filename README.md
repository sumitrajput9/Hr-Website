HR Cloud Frontend
A responsive 4-page front-end web application for HR Cloud, a Human Resource Management System (HRMS), built with React, Vite, and inline CSS. The app includes Home, Services, About, and Contact pages, showcasing features like employee onboarding, attendance tracking, and payroll management. The Contact page features an enhanced contact form with a modern, accessible UI.
Setup Instructions

Clone the repository:
git clone <repository-url>
cd hr-cloud-frontend


Install dependencies:
npm install
and 
start command 
npm run dev


Add placeholder images:

Place the following images in /public/assets/:
logo.png (unused, for future use)
hero-bg.jpg (Home page hero)
service1.png (Employee Onboarding/Tracking)
service2.png (Attendance Tracking/Management)
service3.png (Payroll Management/Insights)
service4.png (Performance Reviews/Leave Approvals)




Run the development server:
npm run dev


Open http://localhost:5173 in your browser.


Build for production (optional):
npm run build
